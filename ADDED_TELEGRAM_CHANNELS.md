## Куда добавлено

1. **`bot/database.py` → `DEFAULT_SOURCES`** — используются парсером поиска вакансий (`search_vacancies_by_resume`). Теперь в базе по умолчанию **21 источник**: 17 ТГ-каналов + 4 сайта (hh.ru API, Хабр Карьера RSS, SuperJob RSS, GeekJob).
2. **`bot/services/resource_catalog.py` → `TELEGRAM_CHANNELS`** — те же каналы показываются пользователю в `/find_resources` (20 каналов, 11 агрегаторов, 30 компаний).
3. **`Database.ensure_default_sources()`** — досеивает отсутствующие источники в **уже работающую базу** при старте бота (в логе: «Добавлено новых источников вакансий в БД: N»).

## Что улучшено попутно

- **Заголовки вакансий**: раньше в Telegram-каналах заголовком становилась строка-эмодзи (`🔥`, `🆕`, `💰`). Теперь `_pick_title_and_snippet()` берёт первую строку с буквами/цифрами — в списке вакансий видно реальное название позиции.
- **Идемпотентность**: повторный запуск не дублирует источники (`INSERT OR IGNORE` + проверка `canonical_url`), тест `test_user_added_hr_channels_in_database` это фиксирует.

## Как обновить работающего бота

1. Загрузите `find_job_in_www_bot.zip` в корень репозитория (workflow распакует и закоммитит).
2. **Actions → Run Telegram Bot → Run workflow** — при старте сработает `ensure_default_sources()`.
3. Проверка в боте: `/sources` → список должен содержать 21 источник; `/search` → «1 месяц» → в результатах появятся посты из новых HR-каналов.
